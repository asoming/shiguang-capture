# 截图操作与小预览 · 1.4.5

依据用户提供的截图参考调整交互，保留原有功能入口。

- 白色紧凑图标工具条：调整选区、矩形、椭圆、箭头、画笔、遮盖、文字、识别翻译、OCR、代码、表格、长截图、撤销、重做、保存、贴图、取消、完成复制。
- 标注工具展开第二行颜色与大小选项；文字字号和画笔粗细按原生像素密度换算。文字仍可再次点击修改，支持撤销。
- 长图小预览固定 176 × 270 逻辑像素，优先放到选区左侧并顶边对齐；全屏或左侧空间不足时放到选区所在屏幕的左上角。兼容负坐标显示器。
- 首帧立即提供缩略图，后续每帧更新。选区外的预览不闪烁；选区内的预览在滚轮输入、抓图时隐藏，防止拦截输入或混入图像。缩略图数据限制在 180 × 420 像素内。

## 验证

- 本机 Linux X11、2× DPI，分别验证选区左侧常驻和选区内隐藏预览：均拼接 11 帧，输出 840 × 3680，与原始合成文档逐像素完全一致。
- Qt 回归覆盖预览位置、全屏与负坐标屏幕、超宽图缩略、颜色／粗细／字号导出、椭圆、文字重编辑、翻译入口和底边工具条布局。
- 本地完整回归：248 passed、3 skipped；原生验证脚本 `scripts/accept_scroll_capture.py` 默认测试预览遮挡目标，可使用 `--outside` 测试左侧常驻。
- 独立 Linux 包在安装前执行 `--check` 与 `--self-test`。
