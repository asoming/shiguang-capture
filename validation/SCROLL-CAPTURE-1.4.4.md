# 长截图修复验证 · 1.4.4

本次针对“不能自动滚动／只截到首屏”。公开正式下载仍以 Releases 中的实际版本为准。

## 原因与修复

- 选区采用 Qt 逻辑坐标，原代码把相同数值传给 pynput 原生鼠标坐标。在本机 2× 缩放 X11 桌面，滚轮落在选区外，测试文档收到 0 次滚轮事件，最终只输出首屏。
- 改用 QCursor 移动和恢复鼠标，由 Qt 处理屏幕缩放；滚轮发送前隐藏预览窗，避免拦截输入。第一次滚轮之前也不显示预览。
- 去除 600 像素的固定重叠上限，直接比较完整的上一帧，保留原生像素行；按选区高度控制滚动步长。
- 不再扩大接近最优值的匹配并返回旧置信度。无法唯一确认重复内容时停止并保留已有部分；没有滚动时给出选区提示。

## 验证结果

本机 Linux X11、2× DPI，使用不含个人数据的合成滚动窗口。预览窗故意覆盖滚轮目标，验证隐藏后仍能正确滚动。

| 项目 | 结果 |
| --- | --- |
| 修复前 | 滚轮事件 0；偏移 0；仅 1 帧 |
| 最终修复 | 滚轮事件 22；偏移 1200 逻辑像素；11 帧 |
| 长图尺寸 | 840 × 3680 像素 |
| 原文档逐像素对比 | 完全一致，无重复／漏行／接缝 |
| 本地回归 | 237 passed，3 skipped（可选集成项） |
| 独立 Linux 包 | `--check`、`--self-test` 通过 |

```bash

QT_QPA_PLATFORM=offscreen SHIGUANG_NO_HOTKEYS=1 pytest
```
