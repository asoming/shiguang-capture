拾光 Capture 1.4.0 提供 Linux X11 x86_64、Windows x86_64 和 macOS arm64 三个平台的独立运行包。

本次更新：

- 截图内直接标注，已输入文字可再次点击修改，支持撤销和重做。修复高 DPI 蒙板下文字失真，以及确认文字时提前退出截图的问题。
- 录屏面板采用左侧设置、右侧预览；开始时显示三秒全屏动效倒计时，Esc 可取消。
- 录制中使用可拖动蓝色浮球，点击展开继续、暂停、停止三个图标，拖到左右边缘收成半圆。
- 识别界面简化为左图右文。点击翻译后显示原文／译文对照，右键可切换上下或左右排列。复制、格式、导出和清理放在右键菜单。
- 随包提供中英双向离线翻译模型；翻译使用校对后的文字，不上传图片或文字，不重新执行 OCR。
- Linux 安装脚本和 Windows 快捷方式脚本随包提供。

安装：Linux 解压后运行 `install-linux.sh`；Windows 解压后运行 `.exe`，可用 `install-windows.ps1` 创建快捷方式；macOS 将 `.app` 移到应用程序目录。macOS 为 ad-hoc 签名，未公证。

验证记录、构建信息和 SHA-256 随本次发布附带。GitHub 托管桌面测试覆盖的范围以报告为准。

已知限制：macOS 原生屏幕采集在云端复测中帧率偏低，本次不作为发布阻断项；macOS 系统音频、物理多屏、权限拒绝恢复等场景仍未完整验收。复杂／合并表格尚不支持，OCR 结果需校对；滚动长截图仍为实验功能。PRD 的全量质量及性能验收尚未完成，逐项记录见仓库 `validation/PRD-ACCEPTANCE.md`。
