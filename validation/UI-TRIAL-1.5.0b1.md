# 拾光 Capture 1.5.0b1 界面试用版

2026-09-25。本轮把交互提案接入实际 Qt 桌面软件，提供本地 Linux X11 试用包。未创建新分支，未发布正式版本；本记录不代替三平台或完整 PRD 验收。

## 本轮变化

- 设置改为白色侧栏，保留全部设置、10 项可配置快捷键及冲突校验；顶部可进入截图、录屏和识别。
- 白色录屏台使用全屏／区域／窗口分段选择、折叠音源、底栏计时与录制按钮；蓝色悬浮球支持键盘展开，贴边时停止无效动画重绘。
- 实时预览中断会有限重试；重试耗尽后提供重新连接。离开录制页、隐藏或最小化时释放采集进程。
- 录屏文件页增加搜索、真实时长、缩略图和安全重命名；保留播放、打开文件夹和回收站删除。视频信息仅按可见文件异步读取，超时可中止，缓存限制 128 项。
- 识别工作台保留左图右文字，加入打开／粘贴入口和更多菜单；模式切换、输出格式、文字整理、表格编辑、TXT／Markdown／JSON／XLSX 导出、翻译对照均接入实际功能。
- 编辑原文、清空会话后不会被旧 OCR／翻译任务覆盖；低置信、复制成功与错误反馈可见。
- 贴图增加位置锁定、缩放与透明度菜单；隐藏后一次快捷键即可恢复。
- 修复试用版升级到同版本正式版的比较；DEB 使用 `1.5.0~b1`，以便正常升级为 `1.5.0`。
- 修复自定义 Qt 光标库路径打包时缺少 SONAME 文件名的问题。
