# 长截图范围边框 · 1.4.7

手动长截图期间保留蓝色选区边框，显示实际捕获区域。边框与小预览使用独立窗口，页面仍由用户自行滚动。

- 边框优先放在选区外，因此普通选区采集时仍能保留边框。
- 贴近屏幕边缘或全屏时，相应边框放在屏幕内侧；仅在抓取像素时短暂隐藏，抓取后恢复。它不会进入拼接结果。
- 边框不接收焦点、鼠标和滚轮；完成、停止或关闭预览时一并关闭。
- 使用透明原生窗口绘制细边框，避免系统添加阴影；页面变化检测排除边框及预览阴影，静止时不反复抓取。

## 验证

- 本地完整回归：253 passed、3 skipped，两个第三方 SWIG 弃用警告。
- Qt 回归覆盖：普通、全屏、负坐标屏幕的边框位置；输入穿透标志；捕获期间隐藏／恢复与结束清理；边框像素不触发空闲抓取。
- 本机 Linux X11、2× DPI，使用独立合成文档验证三种组合：外侧边框与左侧预览、外侧边框与选区内预览、模拟四边贴屏的内侧边框与左侧预览。
- 三种组合均在静止时显示边框且不启动干净帧捕获，手动滚动后更新，到底等待完成，结束关闭边框。每次 20 个滚轮事件、11 帧、840 × 3680 输出，与原始文档逐像素完全一致。
- 贴边测试将鼠标置于蓝色边框上，确认滚轮穿透到原页面。
- GitHub Linux 桌面验收增加贴边用例，保留既有 1×、2× DPI 测试。

本次原生验证范围为 Linux；不据此宣称 Windows/macOS 实机验收完成。
