Installation & compatibility

Windows packages are unsigned. The macOS app is ad-hoc signed, not notarized; recording frame rates may be low and system audio has not passed acceptance. Linux targets X11. Physical multi-monitor and some permission recovery scenarios still need device testing. Read the acceptance record ↗

A few useful details.

Does it work offline?

Yes. Released packages include OCR and Chinese–English translation models. No account or extra model download is required. The website demo uses sample content.

Do screenshots always open the workbench?

No. Annotate, copy, save or pin directly from the selection. The workbench opens for text, code or table recognition.

Can it recognize any table?

The current scope is fully bordered, unmerged tables up to 30 rows × 12 columns. Complex tables are unsupported, scrolling capture is experimental, and recognition results need review.

Can I change the shortcuts?

Open the Shortcuts tab in settings, click an input, press a new combination and save. Defaults: F1 for capture, F6 for recording or pause/resume, F7 to stop and save.

How do I quit the app?

Closing a window leaves the app in the tray so shortcuts remain available. Use the tray menu to quit completely.
