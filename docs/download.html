Python 3.11 / 3.12

git clone https://github.com/asoming/shiguang-capture.git
cd shiguang-capture
python -m venv .venv
# 激活虚拟环境后运行
python -m pip install -e ".[gui,ocr]"
python -m shiguang_capture

Windows 解压运行 .exe，可用 install-windows.ps1 创建快捷方式；macOS 解压后移动 .app 到应用程序目录（ad-hoc 签名，未公证）。Wayland 仍为实验支持。
