下载 Linux 正式版

v1.3.0 正式范围：Linux x86_64 X11。下载压缩包并运行 install-linux.sh，即可建立桌面快捷方式。

Python 3.11 / 3.12

git clone https://github.com/asoming/shiguang-capture.git
cd shiguang-capture
python -m venv .venv
# 激活虚拟环境后运行
python -m pip install -e ".[gui,ocr]"
python -m shiguang_capture

正式范围为 Linux x86_64 X11。Windows/macOS/Wayland 为实验支持，仍需实机验证。
