功能与边界

以当前代码实现为准，区分可用能力和后续工作。

当前实现

  • 区域／当前屏幕截图、PNG/JPEG 打开、拖入和粘贴
  • 箭头、矩形、文字、画笔、实色遮盖、撤销／重做
  • 原图校对、本地文字识别、手动复制、TXT/MD 导出
  • 桌面贴图、取色、设置与手动更新检查
  • 全屏／区域／窗口录屏、三秒倒计时、可拖动贴边浮球
  • 随包中英离线翻译，原文与译文对照

实验能力

长截图只适用于受限静态滚动场景，失败会停止并保留已有部分。macOS 原生采集帧率在云端测试中偏低，系统音频等场景仍待完整验证。

尚未实现
